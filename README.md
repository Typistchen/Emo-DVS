# Event-based Multimodal Emotion Recognition

This repository contains the code used for:

1. FAU-guided event representation pretraining;
2. video-to-event conversion with [v2e](https://github.com/SensorsINI/v2e);
3. visual, audio, and text feature extraction; and
4. information-guided multimodal emotion classification on Ekman6 and VideoEmotion8.

The Emo-DVS dataset download link and usage requirements are provided below. Pretrained checkpoints will be released later.

## Installation

Python 3.10 or 3.11 and a CUDA-enabled PyTorch installation are recommended.

```bash
conda create -n event-emotion python=3.11 -y
conda activate event-emotion
pip install -r requirements.txt
```

FFmpeg is required for audio extraction. Install it with your system package manager and ensure that `ffmpeg` is on `PATH`.

Qwen3-ASR transcription is optional:

```bash
pip install -r requirements-asr.txt
```

Install v2e separately from its official repository:

```bash
git clone https://github.com/SensorsINI/v2e.git third_party/v2e
cd third_party/v2e
pip install -r requirements.txt
cd ../..
```

Please refer to the official v2e repository if its installation requirements change.

## Datasets

Ekman6 and VideoEmotion8 raw videos are available together from the following public Zenodo record:

- Dataset page: <https://zenodo.org/records/17159328>
- Raw videos (`videos.zip`, 22.9 GB): <https://zenodo.org/records/17159328/files/videos.zip?download=1>
- Ekman6 reference features: <https://zenodo.org/records/17159328/files/ekman6_features.pkl?download=1>
- VideoEmotion8 reference features: <https://zenodo.org/records/17159328/files/videoemotion8_features.pkl?download=1>

The supplied `.pkl` files are reference features from the dataset publisher. The training code in this repository expects aligned visual, audio, and text `.pt` files generated by the preprocessing scripts below.

After downloading, arrange the raw videos as follows. Nested directories below each class are supported.

```text
data/raw/
├── Ekman6/
│   ├── anger/*.mp4
│   ├── disgust/*.mp4
│   ├── fear/*.mp4
│   ├── joy/*.mp4
│   ├── sadness/*.mp4
│   └── surprise/*.mp4
└── VideoEmotion8/
    ├── 0-Anger/*.mp4
    ├── 1-Anticipation/*.mp4
    ├── 2-Disgust/*.mp4
    ├── 3-Fear/*.mp4
    ├── 4-Joy/*.mp4
    ├── 5-Sadness/*.mp4
    ├── 6-Surprise/*.mp4
    └── 7-Trust/*.mp4
```

If the downloaded archive uses a different prefix, retain the class name as the final `-`-separated component for VideoEmotion8. For Ekman6, use the lowercase class names shown above.

## Processing pipeline

Run all commands from the repository root. Replace `Ekman6` with `VideoEmotion8` in the paths to prepare the second dataset.

### 1. Convert RGB videos to event streams

```bash
python preprocessing/convert_videos_to_events.py \
  --input-root data/raw/Ekman6 \
  --output-root data/interim/Ekman6_events \
  --v2e-root third_party/v2e
```

Unknown command-line options are forwarded to `v2e.py`, so sensor/noise parameters can be appended to this command. The default output resolution is 224 × 336 and each video is stored as `events.h5`.

### 2. Render and sample event frames

```bash
python preprocessing/events_to_frames.py \
  --input-root data/interim/Ekman6_events \
  --output-root data/interim/Ekman6_event_frames \
  --window-seconds 0.3

python preprocessing/sample_event_frames.py \
  --input-root data/interim/Ekman6_event_frames \
  --output-root data/interim/Ekman6_event_frames_stride3 \
  --stride 3
```

### 3. FAU-guided pretraining

FAU pretraining expects at least 16 event frames per sample:

```text
data/fau_pretrain_frames/
├── FAU1/sample_000/sampled_frame_000.png
├── FAU1/sample_000/sampled_frame_001.png
└── ...
```

Edit `fau_pretraining/configs/train_fau.yaml` if the data or output paths differ, then run:

```bash
python fau_pretraining/train/train_fau.py \
  --config fau_pretraining/configs/train_fau.yaml \
  --world_size 1
```

For multi-GPU training, set `distributed: true` in the YAML file and pass the desired GPU count through `--world_size`.

### 4. Extract 768-D visual features

```bash
python preprocessing/extract_visual_features.py \
  --input-root data/interim/Ekman6_event_frames_stride3 \
  --output-root data/features/Ekman6_visual \
  --checkpoint outputs/fau_pretrain/checkpoints/best.pth
```

### 5. Extract audio and transcripts

Extract 16-kHz mono audio only:

```bash
python preprocessing/extract_audio_and_transcripts.py \
  --input-root data/raw/Ekman6 \
  --audio-root data/interim/Ekman6_audio
```

To also generate transcripts with a local or Hugging Face Qwen3-ASR model:

```bash
python preprocessing/extract_audio_and_transcripts.py \
  --input-root data/raw/Ekman6 \
  --audio-root data/interim/Ekman6_audio \
  --text-root data/interim/Ekman6_text \
  --asr-model /path/to/Qwen3-ASR-model
```

Existing transcripts may instead be placed directly under `data/interim/Ekman6_text`, using the same relative paths and `.txt` file names as the videos.

### 6. Extract 1024-D audio and text features

```bash
python preprocessing/extract_audio_features.py \
  --input-root data/interim/Ekman6_audio \
  --output-root data/features/Ekman6_audio

python preprocessing/extract_text_features.py \
  --input-root data/interim/Ekman6_text \
  --output-root data/features/Ekman6_text
```

The three feature roots must have identical relative paths. Text may be missing; visual and audio features are required.

```text
data/features/
├── Ekman6_visual/anger/example.pt       # [T_v, 768]
├── Ekman6_audio/anger/example.pt        # [T_a, 1024]
└── Ekman6_text/anger/example.pt         # [T_t, 1024], optional
```

## Training

### Ekman6

```bash
python multimodal/train/train_ekman6.py \
  --image_dir data/features/Ekman6_visual \
  --audio_dir data/features/Ekman6_audio \
  --text_dir data/features/Ekman6_text \
  --output_dir outputs/ekman6
```

### VideoEmotion8

```bash
python multimodal/train/train_videoemotion8.py \
  --image_dir data/features/VideoEmotion8_visual \
  --audio_dir data/features/VideoEmotion8_audio \
  --text_dir data/features/VideoEmotion8_text \
  --output_dir outputs/videoemotion8
```

Both scripts implement modality gating, modality-specific/shared/gate projections, symmetric pairwise InfoNCE, fused–shared alignment, residual redundancy minimization, and emotion classification.

The original experiment defaults are retained: `--lambda_mi 0.05`, `--lambda_align 0.005`, and `--lambda_red 0.0`. To activate redundancy minimization, explicitly pass a nonzero value, for example `--lambda_red 0.01`.

## Reproducibility notes

- The scripts use a seeded 66/34 random train/validation split, matching the supplied experimental code.
- Checkpoints and TensorBoard logs are written below the selected output directory.
- Model weights, generated event streams, extracted features, logs, and raw datasets are intentionally excluded from Git.
- The FAU pretraining dataset and pretrained checkpoints will be released later.
